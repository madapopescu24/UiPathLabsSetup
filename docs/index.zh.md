# 🧪 UiPath Labs 环境准备 { #uipath-labs-setup }

**为工作坊准备好你的 UiPath Labs 环境：虚拟机、工作坊账号和租户。按从左到右的顺序完成各个标签页，每一页最后都有一项检查。**

!!! tip "培训环境"
    用你的工作坊账号登录 **[{{ training_url }}]({{ training_url }})**。你会在 **{{ agentic_tenant }}** 和 **{{ training_tenant }}** 这两个租户中操作。

## 🎁 UiPath Labs 为你提供什么 { #what-uipath-labs-gives-you }

工作坊的每位学员都会拿到同样一套现成的环境，所以没有人需要在课上花时间安装工具。

<div class="feature-grid" markdown>

<div class="feature" markdown>
<span class="f-icon">🖥️</span>
<span class="f-title" markdown="span">一台 Windows 虚拟机</span>

一台在浏览器中打开的虚拟机（VM）。**Chrome**、**UiPath Studio** 以及工作坊要用到的工具都已经装好。

</div>

<div class="feature" markdown>
<span class="f-icon">👤</span>
<span class="f-title" markdown="span">一个工作坊账号</span>

专为本次工作坊创建的 UiPath 账号。你用它登录，而不是用你自己的账号。

</div>

<div class="feature" markdown>
<span class="f-icon">🏢</span>
<span class="f-title" markdown="span">两个工作坊租户</span>

租户 **{{ agentic_tenant }}** 和 **{{ training_tenant }}**，其中的 Test Manager、Studio Web 和 Orchestrator 已为练习准备就绪。

</div>

</div>
